| Command                   | អត្ថន័យ                   |
| ------------------------- | ------------------------- |
| `git init`                | បង្កើត Git                |
| `git status`              | មើលស្ថានភាព Files         |
| `git add .`               | Add Files ទាំងអស់         |
| `git commit -m "message"` | Save Version              |
| `git push`                | ផ្ញើ Code → GitHub        |
| `git pull`                | ទាញ Code → Computer       |
| `git clone`               | Copy Repository ពី GitHub |
| `git branch`              | មើល/គ្រប់គ្រង Branch      |
| `git merge`               | បញ្ចូល Branch             |
